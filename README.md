# ŞaşalLauncher

Şaşalistan Cumhuriyeti'nin resmi Minecraft başlatıcısı.

**İndir:** [Releases](https://github.com/whoisch4t/SasalLauncher-releases/releases/latest) sayfasından en yeni `SasalLauncher_x.y.z_x64-setup.exe` dosyasını indirip kur. Sonraki güncellemeleri launcher kendisi kurar.
